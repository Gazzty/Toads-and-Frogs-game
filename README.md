# Toads and Frogs - Juego en Python con Pygame

Este proyecto es una implementación del juego de estrategia **Toads and Frogs** usando [Pygame](https://www.pygame.org/).  

El objetivo es simple pero desafiante: **los toads avanzan hacia la derecha y las frogs hacia la izquierda**, alternando turnos.  
Gana el jugador que logre bloquear al oponente hasta que no pueda moverse más.

---

## Características

- Tablero gráfico con casillas de 100×100 píxeles.  
- Piezas personalizadas (toads y frogs con imágenes SVG o PNG).  
- Movimientos por click, con **resaltado verde** de posiciones válidas.  
- Detección de ganador (Toads o Frogs).  
- Botón **Restart** para reiniciar la partida.  
- Botón **Quit** para salir del juego.
